# 세종 영어 단어 공부 앱

세종 한자공부 앱과 같은 구조로 만든 초등 영어 단어 앱입니다.

| 한자 앱 | 영어 앱 |
|---|---|
| 급수 (8~5급) | Level 1~4 (초등 기본어휘 413개) |
| 훈음읽기 + 훈음 퀴즈 | 단어 익히기(발음 듣기) + 철자 퀴즈 |
| 한자쓰기 | 따라 쓰기 |
| 한자읽기 | 듣고 쓰기 |
| 한자퀴즈 (훈음·읽기·찾기) | 영어 퀴즈 (뜻 고르기·단어 고르기·듣고 고르기) |
| 한자왕 | 영단어왕 (40문제) |
| 내 점수 / 교사용 결과표 | 같음 |

- 단계당 20문제, 70% 이상 맞히면 단계 통과
- 철자 퀴즈·뜻 고르기·단어 고르기·듣고 고르기의 모든 단계를 통과하면 그 Level '통과'
- 로그인 정보 저장, 음악은 버튼을 눌러야 재생 (한자 앱 수정 사항 그대로 반영)
- 교사용: 이름에 `교사용` 입력 → 학급 결과표

---

## 1단계. Firebase(학생 기록 저장소) 만들기 — 처음 한 번만

1. https://console.firebase.google.com 에 구글 계정으로 접속 → **프로젝트 만들기**
   - 이름: `sejong-english` (아무거나 가능)
   - Google 애널리틱스는 **사용 안 함**으로 꺼도 됩니다 → 프로젝트 만들기
2. 왼쪽 메뉴 **빌드(Build) → Firestore Database → 데이터베이스 만들기**
   - 위치: **asia-northeast3 (서울)** 선택
   - **프로덕션 모드**로 시작 → 만들기
3. Firestore 화면 위쪽 **규칙(Rules)** 탭 → 들어 있는 내용을 지우고
   이 폴더의 `firestore.rules` 내용을 붙여넣기 → **게시**
4. 왼쪽 위 **프로젝트 개요** 옆 ⚙️ → **프로젝트 설정** → 아래쪽 **내 앱**에서 **Android 아이콘** 클릭
   - Android 패키지 이름: **`com.sejong.sejong_english`** (정확히 똑같이)
   - 앱 닉네임은 아무거나 → **앱 등록**
   - **google-services.json 다운로드** 버튼으로 파일을 받습니다
   - 그 뒤 단계(SDK 추가 등)는 모두 **다음 → 콘솔로 이동**으로 넘기면 됩니다

## 2단계. GitHub에서 APK 만들기

1. GitHub에서 **새 저장소**(Private) 만들기 (예: `sejong-english`)
2. **uploading an existing file** → 이 폴더 안의 내용 전체 + 위에서 받은 **google-services.json** 을 함께 끌어다 놓고 **Commit changes**
3. **Actions** 탭에서 빌드 확인 (약 10분)
   - 빌드가 안 보이면: Actions → **set up a workflow yourself** → 파일 이름 `build-apk.yml` → 이 폴더의 `build-apk.yml` 내용 붙여넣기 → Commit
4. 초록색 ✓ → 실행 클릭 → 아래 **Artifacts → sejong_english-apk** 내려받기 → 압축 풀면 `sejong_english.apk`
